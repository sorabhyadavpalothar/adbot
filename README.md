# 🚀 AIBOT — Telegram Multi-Account Auto-Forwarder & Management System

High-performance, enterprise-grade Telegram auto-forwarder bot built with **Python 3.10+**, **Telethon**, **python-telegram-bot v22**, **PostgreSQL**, and **Redis**.

Supports managing multiple linked Telegram accounts simultaneously with independent per-account worker loops, smart rate-limit isolation, forum topic management, auto closed-topic fallbacks, per-user log channels, and India Standard Time (IST) logging.
